GitHub — это облачный сервис для хостинга IT-проектов и их совместной разработки, использующий систему контроля версий Git. Команды push (отправка) и pull (получение) нужны для синхронизации локального кода на компьютере с удаленным репозиторием (на GitHub), обеспечивая создание резервных копий и совместную работу.

Зачем нужны команды Push и Pull
Они обеспечивают обмен данными между вашим компьютером и сервером GitHub.
git push (Отправка):
Суть: Отправляет ваши локальные коммиты (изменения) из вашего компьютера в удаленный репозиторий.
Зачем: Обновить общий код, поделиться результатами с командой, сделать резервную копию.
Пример: git push origin main — отправить ветку main на сервер origin.
git pull (Получение/Слияние):
Суть: Скачивает изменения из удаленного репозитория и автоматически объединяет их с вашим локальным кодом.
Зачем: Получить актуальную версию проекта, над которой работали другие участники.
Пример: git pull origin main — забрать изменения из ветки main с сервера.
